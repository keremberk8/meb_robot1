## 📌 Overview

This repository contains embedded/robotics development work for the MEB robotics project. It keeps controller-specific firmware separated for easier testing and iteration.

## 📁 Structure

See the controller directories below and open the relevant Arduino sketch in Arduino IDE.

## 🧪 Development

Select the matching Arduino board and port in Arduino IDE, verify wiring and pin assignments, then upload the selected sketch.

## 🎯 Purpose

The project is a practical workspace for experimenting with robot control, sensors, motors and hardware configurations.
